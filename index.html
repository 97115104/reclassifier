About Reclassifier

Reclassifier is a serverless tool for adding, editing, and reclassifying fields in JSON data.

Primary use case: Reclassing AI-generated data or JSON objects to build more consistent and repeatable AI workflows. When AI outputs need human review, correction, or enrichment, Reclassifier lets you walk through each object one at a time and add or edit fields interactively.

Common uses

  • Add classification labels (genre, category, type) to AI-generated datasets
  • Edit or correct existing fields across many objects
  • Enrich JSON exports with human review scores or notes
  • Tag and annotate data for fine-tuning or evaluation pipelines
  • Standardize inconsistent field values across a collection

How it works

  1. Upload a JSON file
  2. Choose fields to add or existing fields to edit
  3. Walk through each object, filling in values
  4. Download the updated JSON

All processing happens locally in your browser. No data is sent to any server.
